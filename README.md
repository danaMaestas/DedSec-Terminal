# DedSec Terminal

A custom terminal project written in Python and inspired by the atmosphere of DedSec from Watch Dogs.

Created by **dana_maestas**

## Features

- Custom terminal interface
- ASCII art system
- Multiple selectable arts
- Custom username
- Johnny chatbot
- Built-in commands
- Animated terminal messages

## Commands

`help` — show available commands  
`about` — information about the terminal  
`clear` — clear the terminal  
`johnny` — start Johnny  
`setname` — change username  
`change art` — change terminal ASCII art  
`exit` — close the terminal

## Requirements

- Python 3
- Windows

## How to run

Clone or download the project, open the project folder and run:

```bash
python dedsec_fixed.py
```

Or launch:

```text
DEDSEC.bat
```

## Project structure
